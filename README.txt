Basics of Vedic Astrology: A Complete Beginner's Course (installable app)
ASTROSUTRAS by Anoopam Shukla
==========================================================================

USE IT ON THIS COMPUTER
  Double-click index.html. It opens in your browser and needs no server and no internet.
  Your progress, notes, bookmarks and written answers are saved in that browser, on that device only.
  (Keep all the files together, exactly as they are in this folder.)

PUT IT ON THE INTERNET AND INSTALL IT ON A PHONE
  Upload the CONTENTS of this folder to GitHub Pages, Netlify Drop or your own web site (the address must
  start with https). Keep the folders "data" and "assets" as folders. Every file address in the app is
  relative, so it works at the top of a site (https://example.org/) and inside a folder of a site
  (https://your-name.github.io/vedic-basics/) alike.
  Then open the address on the phone: Android Chrome menu > Install app, iPhone Safari Share > Add to Home Screen.
  Under More in the app, "Download everything for offline use" keeps the whole course on the device (about 8 MB).
  Simple step-by-step instructions: the file HOW-TO-PUBLISH-THE-BASICS-APP.txt, which the course owner keeps
  next to this folder (it is a guide for the person who publishes, not one of the files to publish).

WHAT IS IN THIS FOLDER
  index.html       the program (open this one)
  data\            the course text, one folder per language (data\en = English), loaded page by page;
                   data\langs.js lists the languages
  assets\team\     the four team photographs (publish only with each person's consent)
  sw.js            lets the installed app work without internet
  manifest.json, icon.svg, icon-180.png, icon-192.png, icon-512.png    what a phone needs to install the app
  404.html         sends a mistyped address back to the course (GitHub Pages shows it for unknown addresses)
  .nojekyll        tells GitHub Pages to publish the files exactly as they are
  README.txt       this note

LANGUAGES
  English now. A Hindi edition can be added later without changing the program: the build adds a data\hi
  folder, a new data\langs.js and an index.html that contains the translated interface dictionary, and the
  language button in the header then appears by itself. Progress is kept per page, so it is shared between
  languages. A page that is not translated yet is shown in English.

UPDATING LATER
  Upload the new files over the old ones (same names). The app picks up the new version the next time it is
  opened with internet. Progress, notes and answers stay on each device.

NOTE
  The course teaches Jyotish for learning and reflection. It is not scientifically validated prediction and
  not medical, legal, financial or counselling advice. The worked-example and exam charts are hypothetical
  (constructed for teaching, not real people); the three case studies of Module 14 use the published birth
  data of public figures and label what is uncertain as provisional.
  The app itself has no server, no account, no tracking and calls no other web site: everything the reader
  writes stays in that reader's own browser.
